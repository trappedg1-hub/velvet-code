# VELVET CODE

**18+** Взрослая визуальная новелла/игра в стиле реальной манхвы и хентай-аниме.
Репозиторий содержит спрайты и промпты откровенного содержания. Не для несовершеннолетних.

## Что здесь есть

| | |
|---|---|
| **7 героинь** | selena 178 · mika 170 · yuna 158 · reika 172 · nova 166 · sora 154 · irene 174 см |
| **Спрайты** | `assets/sprite/m_*.webp`, прозрачный фон, истинный масштаб, якоря скелета в `manifest.json` |
| **Канон** | `canon/source/style-v12.json` — 46 утверждённых элементов стиля, архив v5…v11 |
| **Прототип** | `prototype/index.html` — вертикальный срез в одном файле, 0 внешних запросов, гейт 18+ |
| **Пайплайн** | `tools/` — форж промптов, ткань как физика, стопа, смелость, негатив, ремонт артефактов |
| **Арена** | `automation/arena_loop.py` поверх `vendor/arena-skill` — турниры вариантов с судейством |

## Как читать проект

Порядок для человека и для агента одинаковый:

1. **`MEMORY.md`** — что уже знаем: состояние и числа, журнал заходов, внешние источники, тупики.
2. **`HANDOFF.md`** — что делать: утверждено/отклонено, инструменты, очередь работ.
3. **`AGENTS.md`** — правила работы: гейты, формат отчёта, границы.
4. **`TRANSFER.md`** — как передать проект дальше.

Режим работы — **mature**; green — витрина и гейт 18+. Возраст персонажей подтверждён,
правило 18+ проверяется в CI.

## Чего в репозитории нет

`assets/raw/` (промежуточные кадры на хромакее), `review/*.html` (отчёты на утверждение),
`.arena/`, кэши. Всё восстанавливается: промпты каста — `assets/prompts/renders_v11.jsonl`,
спрайт из кадра — `make repair && python3 tools/pipeline_sprites.py --name m_selena`,
отчёт — `python3 automation/review.py`.
