# AGENTS.md — инструкция для любого кодинг-агента

Проект: **VELVET CODE** — браузерная игра в жанре эччи/hot-fanservice (манхва-стилистика).
Стек: Python 3.13 (фабрика контента) + статический HTML/JS (прототип) → далее Next.js.
Пакетный менеджер: **нет** (Python stdlib + PIL/numpy/pytest). Не добавляй зависимости без разрешения.

## Команды (запускай их, а не догадывайся)

```bash
make test          # pytest tests -q  — обязано быть зелёным перед коммитом
make canon-check   # гейт: утверждённый канон не разошёлся. Ненулевой код = СТОП
make canon-render  # пересобрать review/canon-v1.html (лист на утверждение)
make sync          # подтянуть canon/source/*.json в реестр
make probe         # диагностика подключения к «мозгу» (ArenaAgentBridge / mock)
python3 -m automation.canon list --status draft   # что ждёт утверждения
```

## Границы (трёхуровневая модель)

**Всегда:**
- Прогонять `make test && make canon-check` перед тем, как сказать «готово».
- Генерировать продакшн-контент **только** из элементов канона со статусом `approved`.
- Любой новый арт/персонаж/механика → добавить в `canon/source/*.json` со статусом `draft` и пересобрать лист на утверждение.

**Спросить человека:**
- Изменение утверждённого элемента канона (`canon.json` → `approved`).
- Новые зависимости, платные API, изменение структуры `content/characters/*.json`.
- Всё, что касается денег, платежей, возраста, ToS.

**Никогда:**
- Не менять `canon/canon.json` вручную — только через `python3 -m automation.canon approve|reject`.
- Не поднимать `spice-policy` выше утверждённого уровня.
- Не вырезать и не отключать тесты, чтобы «позеленело». Не `--no-verify`. Не force-push.
- Не вставлять в промпты теги живых артистов (см. `style-core.hard_rules`).
- Не тащить `ArenaAgentBridge` в рантайм игры: это dev-инструмент, у него ToS-риск и капча.

## Карта репозитория

| Путь | Что это |
|---|---|
| `canon/` | реестр утверждений. `source/*.json` — человекочитаемый вход, `canon.json` — состояние |
| `content/characters/*.json` | героини как данные (зоны, реплики, скины). Единственный источник правды о персонаже |
| `automation/` | `canon.py` (гейт), `review.py` (лист на утверждение), `agent_client.py` (мозг) |
| `assets/raw` → `assets/sprite` | сырые рендеры → игровые спрайты (`tools/pipeline_sprites.py`) |
| `prototype/` | работающий вертикальный слайс, один файл, без зависимостей |
| `docs/` | досье: 01 жанр · 02 арт · 03 иммерсивность · 04 мозг · 05 бизнес · 06 роадмап · 09 arena-ops |
| `ROADMAP.json` | машинночитаемая очередь задач — бери следующую через `make next` |

## Формат отчёта о завершении

```
СДЕЛАНО: <1–2 строки>
ПРОВЕРЕНО: make test (N passed) · make canon-check (ok|drift)
ФАЙЛЫ: <список>
ЖДЁТ ЧЕЛОВЕКА: <что нужно утвердить / решить, или "нет">
```

## Когда застрял

- Тест падает 3 раза подряд → стоп, покажи вывод, не «чини» удалением теста.
- `captcha_required` / `login_required` от моста → это задача человека, не ретрай.
- Не уверен в уровне откровенности → смотри `spice-policy` в каноне, при сомнении бери ниже.
