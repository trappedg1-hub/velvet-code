# 02 · Премиум-генерация арта

Цель: **одна героиня = 200+ артов, где лицо, тело, костюм и стиль не плывут.** Ниже — рабочая схема, а не список «попробуйте эти модели».

---

## 1. Выбор базовой модели (состояние на ноябрь 2026)

| Модель | Что это | Плюсы | Минусы |
|---|---|---|---|
| **Anima Turbo v1.1** (CircleStone Labs × Comfy Org) | 2B DiT, файнтюн NVIDIA Cosmos-Predict2-2B-T2I, знания аниме до 09.2025 | 8–12 шагов, CFG 1 → **дешёвый и быстрый**; лучший старт для итераций | чуть ниже качество, чем Aesthetic |
| **Anima Aesthetic v1.1** | тот же движок, дообучен только на качественных данных | максимальное качество «из коробки» | 30–50 шагов, CFG 4–5 → дороже |
| **Anima Base v1.0** | необработанная база | **единственная правильная база для обучения LoRA** | «сырой» вид |
| **Anima-2.9B** (комьюнити, Gazingstars123) | 28 → 40 слоёв, ~2.9B | заметно богаче детализация | молодой, нестабильный, нужен отдельный нод |
| **Illustrious XL v2.0 / NoobAI XL** | SDXL-линия, теги Danbooru | **огромная библиотека готовых LoRA и ControlNet**; зрелая экосистема | ниже потолок качества, 1536² нативно |

**Решение:** производство — на **Anima**, причём:
- итерации и промпт-инженерия → `anima-turbo-v1.1` (CFG 1, 8–12 шагов, euler);
- финальные рендеры → `anima-aesthetic-v1.1` (CFG 4.5, 32 шага, er_sde);
- обучение LoRA → `anima-base-v1.0`;
- **если нужен готовый ControlNet/готовые LoRA-адаптеры** → временно Illustrious/NoobAI (там экосистема на порядок богаче).

Файлы раскладываются так:

| Файл | Куда |
|---|---|
| `anima-turbo-v1.1.safetensors` / `anima-aesthetic…` | `ComfyUI/models/diffusion_models/` |
| `qwen_3_06b_base.safetensors` (текстовый энкодер) | `ComfyUI/models/text_encoders/` |
| `qwen_image_vae.safetensors` | `ComfyUI/models/vae/` |

Промпт-формат Anima — **смесь Danbooru-тегов и естественного языка**, качественный префикс: `masterpiece, best quality, score_7, safe`. Для Aesthetic-версии quality-теги опциональны.

## 2. Лестница консистентности персонажа

Это главное. 90% времени у новичков уходит именно сюда.

### Уровень 1 — «замок» (бесплатно, работает только внутри одного батча)

Фиксируем: seed, промпт-блок внешности (одна и та же строка символов), сэмплер, CFG, разрешение. Даёт 70% совпадения на 5–10 артах. Дальше лицо начинает дрейфовать — это нормально и ожидаемо.

### Уровень 2 — Reference-адаптеры (без обучения, 10 минут)

| Инструмент | Как работает | Где |
|---|---|---|
| **Anima Ref Adapter** (ElectronGirl, 10.2026) | rank-32 LoRA (45.9M), берёт волосы/глаза/костюм с одного референса, позу и сцену — из промпта | GitHub + HF `anima-ref-adapter` |
| **Anima IP-Adapter** (Wenaka2004) | SigLIP2-фичи → decoupled cross-attention в 28 блоках DiT | GitHub `comfyui-anima-ipadapter` |
| **IP-Adapter FaceID PlusV2** (SDXL-семейство) | держит именно лицо | `models/ipadapter/` |

Честное ограничение: reference-адаптеры дают **хорошую консистентность в рамках одной картинки или короткой серии**, но на длинной серии лицо всё равно уплывает. Это не баг, это природа метода.

### Уровень 3 — LoRA персонажа (единственный способ «залочить» героиню по-настоящему)

Рецепт, который работает:

| Параметр | Значение |
|---|---|
| База | `anima-base-v1.0` (или Illustrious v2.0 STABLE) |
| Датасет | **55–60 чистых артов**: 8–10 лиц крупно, 20 торс/поза, 25 полный рост, 5–8 ракурсов ног/стоп, 2–3 разных освещения |
| Капшены | автотеггер (JoyTag / CivitAI tagger) **+ обязательный ручной проход**: убрать «чужие» теги, оставить только то, что правда на картинке |
| Тренер | `kohya_ss` |
| Dim / Alpha | 64 / 32 |
| UNET LR / TE LR | 3e-4 / 3e-5 |
| Шаги | 1000–3000 (следить по превью, а не по цифре) |
| Batch | 1–4 |

Правило датасета: **конгруэнтность важнее размера**. 40 идеально чистых артов одного стиля дадут лучшую LoRA, чем 200 разношёрстных. Никаких водяных знаков, обрезанных рук, чужих артист-тегов.

### Уровень 4 — Edit-модель для поз и костюмов (новое и очень важное)

**Qwen-Image-Edit-2511** (Apache 2.0, есть GGUF для потребительских GPU) — на сегодня лучший открытый инструмент «сохранить личность, поменять всё остальное»:

- «та же девушка, три четверти, идёт» — лицо и пропорции держатся;
- нативная поддержка ControlNet (keypoints / depth / edge) → **позу задаём скелетом, а не словами**;
- мульти-референс: персонаж + сцена + одежда в одном кадре;
- из одного портрета собирается **turnaround sheet** (вид спереди/сбоку/со спины) — а это уже вход в 3D, если понадобится.

В ComfyUI есть готовый one-click пайплайн `Consistent Character Creator`, который из одного портрета делает пак: turnaround, крупные планы, наборы одежды, вариации поз.

**Слабое место:** экстремальные позы и мелкая моторика рук — там дрейф возвращается. Для таких кадров — отдельный проход инпейнта.

### Итоговая схема на одну героиню

```
1. 20–30 «концепт-рендеров» на Turbo        → выбрать лицо и стиль
2. Отобранные 8 → Qwen-Image-Edit-2511      → выровнять в один стиль/свет
3. LoRA на 55–60 артов (~2–4 ч на 4090)
4. Продакшн-рендеры: Aesthetic + LoRA 0.7–0.85
5. Поза: ControlNet keypoints (подготовленные позы-скелеты)
6. Детализация: face/hand/foot detailer pass
7. Апскейл: Real-ESRGAN 4x (или SUPIR для «дорогого» вида)
8. QA-чеклист (ниже) → ретушь руками, если нужно
```

## 3. Управление ракурсами (то, что делает «премиум»)

Словами «покажи ноги» модель не управляется — она управляется **тегами камеры + тегами кадра**. Рабочий словарь (Danbooru-совместимый):

| Задача | Теги |
|---|---|
| Полный рост | `full body, standing, feet out of frame (×)`, `cowboy shot`, `from head to toe` |
| Акцент на ноги | `long legs, full body, from below, low angle, wide hips, standing on one leg` |
| Обувь в кадре | `high heels, stiletto heels, ankle strap, footwear focus, from side` |
| Чулки/колготки | `pantyhose, black pantyhose, thighhighs, zettai ryouiki, sheer legwear` |
| Поза | `hand on hip, contrapposto, leaning forward, arched back, legs crossed, sitting, crossed legs` |
| Камера | `from below, from side, dutch angle, fisheye, close-up, depth of field` |
| Свет | `rim light, backlighting, volumetric lighting, neon light, cinematic` |
| Премиум-стиль | `manhwa style, webtoon, thick lineart, glossy skin, detailed fabric folds` |

**Правило продакшна:** каждая сцена строится как `поза-скелет (ControlNet) + теги костюма + теги камеры`. Никогда не полагаться на длинное текстовое описание позы — модель его игнорирует выборочно.

**Отдельный пайплайн «фут-фокус»** (ваша ключевая визуальная тема): кадры `from below` + `footwear focus` генерируются стабильно плохо в полный рост на 1024px. Решение — генерировать **кроп-сцену отдельно** (`lower body, legs focus, high heels, close-up on footwear`) в разрешении 1536², а не вырезать из общего арта. Качество стоп и обуви — первое, что ломается при апскейле, поэтому порядок такой: **генерация в высоком разрешении → детализация → апскейл**, а не наоборот.

## 4. Слои для Live2D (мост в `03-immersion.md`)

Единственный открытый инструмент уровня «продакшн» — **See-through** (shitagaki-lab, SIGGRAPH 2026):

- один арт → до **23–24 семантических слоёв** с инпейнтингом (волосы спереди/сзади, лицо, глаза, зрачки, рот, одежда, обувь, ноги);
- псевдо-глубина на каждый слой (файнтюн Marigold) → правильный порядок отрисовки;
- выход — **PSD**, готовый для Live2D Cubism;
- ComfyUI-нода: `jtydhr88/ComfyUI-See-through` (workflow `seethrough-basic.json`, res 1280, 30 шагов).

Реальность по железу (замеры сообщества): 3090 — **~25 минут** на один персонаж; на 12 GB VRAM падает или уходит в своп → нужен offload или облако. Планируйте как пакетную ночную операцию, а не интерактив.

⚠️ Ограничение: арт должен быть **фронтальным, с чистым силуэтом и разделёнными конечностями**. Не «экстремальная поза» — иначе слои слипаются и риг будет мусорным.

## 5. Апскейл и «премиум-чёткость»

| Задача | Инструмент |
|---|---|
| Универсальный 4x | **Real-ESRGAN** (`ncnn-vulkan` — работает даже без CUDA) |
| «Дорогой» вид, максимум деталей | **SUPIR** (медленно, для ключевых артов) |
| Реставрация/оживление текстуры | **SeedVR2** |
| Мелкие детали (лицо, кисти, обувь) | inpaint-детейлер по маске, не общий апскейл |

Порядок: генерация в нативном разрешении модели → детейлер проблемных зон → апскейл → **финальный ручной чек**.

## 6. QA-чеклист (проходить каждый арт, иначе стыдно)

- [ ] Лицо совпадает с эталоном героини (сравнение side-by-side, а не «на глаз»)
- [ ] Пальцы: 5, без слияний; кисти не «плавники»
- [ ] Стопа/каблук: пятка в туфле, ремешок не врезается в кожу, шпилька не раздваивается
- [ ] Швы и складки ткани логичны, нет «второй груди» из складки
- [ ] Волосы не прорастают сквозь одежду
- [ ] Фон не «протёк» в силуэт (критично для слоёв)
- [ ] Нет артист-тегов/подписей/водяных знаков
- [ ] Одежда соответствует дизайну персонажа (цвет, крой, пуговицы)
- [ ] Пропорции: в стиле манхвы ноги длиннее натуральных — но не «резиновые»

Это то, на чём инди-проекты горят уже после релиза.

|---|---|---|

| Anima Ref Adapter **ноды** | Apache-2.0 | код свободен, веса — нет |
| **Qwen-Image-Edit-2511** | **Apache-2.0** | можно коммерчески — самый безопасный выбор |

| **IndexTTS-2.x** | Bilibili Model License | нужен отдельный грант на коммерцию |
| See-through | проверить репозиторий | исследовательская лицензия |
| pixi.js / pixi-live2d-display | MIT | безопасно |
| **Live2D Cubism SDK** | отдельная лицензия Live2D Inc. | **обязательна к покупке/регистрации для коммерческого релиза** — не забыть в бюджете |

**Практический план:**
1. Написать в CircleStone Labs о коммерческой лицензии Anima **сейчас** (пока проект маленький — дешевле).
2. Если откажут — производство на **Illustrious/NoobAI + собственные LoRA** (нужна сверка их лицензии) или на Qwen-Image (+ LoRA на него).
3. Аудио: GPT-SoVITS (MIT) как основной, IndexTTS — только после гранта.
4. Юридически зафиксировать: возраст всех персонажей — **явно 18+** в дизайн-документе, в игре и в ToS. Это не формальность, это защита.

## 8. Стоимость арт-пайплайна

| Вариант | Цена |
|---|---|
| Локально, RTX 4090 (своя) | ~$0 + электричество; Turbo ~1.5–3 с/арт, Aesthetic ~8–15 с |
| Облако (fal.ai) | $0.01–0.08 за изображение → 200 артов = **$2–16** |
| See-through (нужен 24 GB) | облачный GPU: H100 ~$2–4/час → ~$10–20 на персонажа |
| LoRA-тренировка | 2–4 ч на 4090 или ~$3–8 в облаке |

**Итого одна героиня с нуля до играбельного Live2D:** ~$50–150 вычислительных затрат + 2–3 дня работы. Это и есть ваше преимущество — не экономьте на QA, экономьте на объёме.
