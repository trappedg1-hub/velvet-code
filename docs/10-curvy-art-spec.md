# 10 · Curvy-спека арта (канон v3)

Документ фиксирует то, что было **отклонено** в каноне v2 и что принято вместо этого.
Это не «пожелания к стилю», а проверяемые условия приёмки: спрайт, не прошедший
`make qa`, в продакшн не идёт.

## 1. Что отклонено (не возвращаться)

| Ось | v2 (отклонено) | Причина |
|---|---|---|
| Пропорции | 8.0–8.6 голов | читается как вытянутая «модельная» фигура |
| Ноги | leg ratio 0.56–0.59 | даёт худобу при широких бёдрах |
| Силуэт | «агрессивная S-линия» на тонкой базе | нет объёма, нет фан-сервиса |
| Общее | элегантная худоба | прямая формулировка владельца: «фигуры должны быть более фан-сервисными, более объёмные» |

Единственная принятая из v2 — Селена в серебристом платье: `assets/sprite/selena_v2.webp`.
Она остаётся эталоном «принятой фигуры» и не перезаписывается.

## 2. Что принято (v3, проверено на 7 рендерах)

| Ось | Требование |
|---|---|
| Голов | **7.6–8.0** |
| Грудь | **huge** — не меньше размера головы; допускается **gigantic** (> 2× головы) у 2 из 7 |
| Бёдра | **шире плеч**, визуальное hip:waist ≈ **1.55–1.75** |
| Бёдра-ноги | диаметр каждого бедра ≈ обхват талии (`thick thighs`) |
| Талия | узкая, но мягкая линия — «резиновый» излом запрещён |
| Силуэт | hourglass / curvy, читается на 25 % масштаба |
| Лицо | V-line, миндалевидные глаза, полные губы; возраст читается как 26–33 |
| Защита | объём даётся формой, а не деформацией: колено, стопа, кисть прорабатываются |

Бори-теги (это же — производственный словарь, см. `style-core` → `tag-vocab`):

```
curvy, voluptuous, huge breasts, wide hips, thick thighs, narrow waist,
hourglass figure, mature female
```

Лестница размеров для вариаций: `flat · small · medium · large · huge (≥ головы) · gigantic (> 2× головы)`.
Синонимы из бори-таксономии: `curvaceous`, `voluptuous`; `big_thighs` / `huge_thighs` / `thunder_thighs`;
`pear-shaped figure`, `plump`, `shortstack`.

## 3. Ecchi-рендер (то, что делает объём «горячим», а не «толстым»)

- **кожа**: глянцевые specular-блики по кривизне (плечо, грудь, бедро, колено), подповерхностное рассеивание;
- **румянец**: градиент + штриховка blush-линий у скул;
- **ткань**: полупрозрачная/влажная, натяжение на груди и бёдрах, visible underboob / sideboob где позволяет костюм;
- **акцентная триада**: грудь → бёдра → стопы/обувь;
- **камера**: низкий ракурс, камера на уровне бёдер;
- **вторичная динамика**: микро-колебание бедра и груди закладывается в позу и в риг.

## 4. Кадр — жёсткое условие

> Персонаж занимает **≤ 80 %** высоты кадра; над волосами и под обувью остаётся зазор;
> обувь целиком в кадре. Обрез по краю = брак.

Первый прогон QA дал ложную тревогу на всех 7 спрайтах: проверялся **уже обрезанный**
по альфе спрайт, а он по построению касается всех четырёх краёв. Проверять кадр можно
только на **сыром** рендере до трима — так и делает `tools/qa_sprites.py`:

```
make qa     # кадр (до трима) · альфа · высота 1200 · aspect · бюджет 400 КБ
```

## 5. Промпт-стек (собрано из практик GitHub + документации Pony/Illustrious)

Структура: **качество → субъект → тело/объём → костюм/поза → камера/свет**. Негатив ≈ 30 % результата.
Seed фиксируется на время итерации весов, иначе сравнивается не то.

| Модель | Как писать |
|---|---|
| Pony V6 | тиры `score_9…score_4_up` + `source_anime` + `rating_questionable/explicit`; **CLIP skip 2 обязателен** |
| Pony V7 | тиры ослаблены — использовать `score_8` |
| Illustrious XL | бори-теги как есть, нативное 1536² |
| Flux | естественный язык, тиры других семейств не смешивать |

Веса: `(tag:1.2)`, рабочий диапазон **0.7–1.5**; приоритет — объём тела 1.25–1.4, костюм 1.1–1.2, камера 1.0–1.15.

### Синтаксис раскрытия (работает локально, `tools/prompt_build.py`)

| Форма | Смысл |
|---|---|
| `{a\|b\|c}` | один случайный вариант, вложенность разрешена |
| `{2$$__body_curvy__}` | 2 строки из файла без повторов |
| `__body_curvy__` | строка из `assets/wildcards/body_curvy.txt` |
| `__outfit*__` | глоб по файлам wildcard |
| `@once{}` | значение один раз на батч (распределение поз) — в ферме |
| `@if{bust=huge, underboob\|alt=sideboob}` | блок по условию — в ферме |

Набор файлов: `assets/wildcards/{body_curvy, pose_ecchi, outfit_l2plus, camera}.txt`.
Источники практик: `adieyal/dynamicprompts`, `mattjaybe/sd-wildcards`,
`whitevamp/civitai-wildcard-prompt` (83 833 файла промптов), `OldBlackJoe/sd-dynamic-prompts`
(`@if{}` / `@once{}` / `@anima{}`).

### Смелые приёмы, которые вошли в стандарт

1. Негатив против «модельной» худобы прямо в базовом блоке: `slim body, thin legs, flat chest, narrow hips`.
2. Вес объёма выше веса костюма — иначе ткань «съедает» форму.
3. Anatomy-gated блоки: underboob только при huge/gigantic.
4. Кадр формулируется как правило: «персонаж ≤ 80 % высоты, обувь целиком в кадре».
5. Один персонаж = один wildcard-набор костюма: перебор идёт по позе и камере, а не по персонажу.

## 6. Производственный цикл (как это собирается)

```
wildcard-шаблон → Anima Turbo / Illustrious (1536², seed фикс)
  → chroma-key #00FF00 → despill → erode → trim/pad 1200 px → WebP
  → make qa (кадр до трима!) → manifest.json → игровой спрайт
  → See-through (слои) → image2live2d (риг) → Pixi v8 → Wan2.2 Animate (анимации)
```
