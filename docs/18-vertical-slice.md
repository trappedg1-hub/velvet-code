# 18. Вертикальный срез: каст в рантайме

Каст v11 утверждён владельцем целиком. Дальше начинается рантайм: спрайты должны стоять на полу
в правильном масштабе, героиня должна переключаться, а взрослый контент — не открываться сам.

## Что собрано

`prototype/index.html` — один самодостаточный файл (733 КБ): спрайты внутри base64, **внешних
запросов 0**. Собирается из карточек и манифеста командой:

```bash
python3 tools/build_slice.py            # → prototype/index.html
python3 tools/rig_anchors.py --all      # якоря скелета → manifest.json
```

Что внутри:

- **семь героинь** — переключение по полосе миниатюр, у каждой свой акцентный цвет из `palette`;
- **истинный масштаб** — 180 см = 72% высоты сцены, общая линия пола, линейка роста на 180/160/140/120;
- **якоря скелета** в подвале — плечи, бёдра, стопы в пикселях (считает `rig_anchors`);
- **режим Green / Mature** с возрастным гейтом: mature спрашивает подтверждение 18+ и меняет
  и бейдж, и реплики;
- **доверие** (0–10) двигает тон: cold → neutral → warm; «сказать про внешность» и «рассмотреть»
  дают разное на разных уровнях;
- **карточка героини**: роль, архетип, фигура, одежда с названием образа, поза, темперамент, давление.

## Якоря: почему по силуэту, а не на глаз

`tools/rig_anchors.py` берёт альфа-маску и считает ширину тела по строкам:

| уровень | как найден |
|---|---|
| верх и низ | крайние непрозрачные строки |
| плечи | максимум ширины в верхней четверти |
| бёдра | максимум ширины в нижней половине |
| талия | минимум ширины между ними |
| колени, щиколотки | доли роста от низа (в длинном платье силуэт ответа не даёт) |

Результат пишется в `assets/sprite/manifest.json → m_*[anchors]`. Переиндексация манифеста
теперь **сохраняет** якоря — иначе срез оставался без точек скелета (это был реальный баг,
на него есть тест).
