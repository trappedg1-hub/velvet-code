# VELVET CODE — досье проекта

**Браузерная игра в жанре эччи / hot fanservice. Премиум-стилистика манхвы.**
Дата сборки досье: 20.11.2026 · режим: agent mode

---

## TL;DR — пять решений, которые определяют всё остальное

| # | Решение | Почему именно так |
|---|---------|-------------------|
| 1 | **Жанр: гибрид «VN-отношения + лёгкий idle-менеджер»**, не гача | Гача требует контента на 200+ артов и математики баланса — это убивает инди-команду. Idle+коллекция скинов даёт retention и монетизацию при 6–10 героинях. Гача — потом, как второй слой. |
| 2 | **Откровенность: уровень Nikke / BD2** (намекающая, не порно) | Это не мораль, это деньги: карточные эквайеры, Steam, Google/Apple и реклама открыты только для «suggestive». Порно = Nutaku + Segpay + битва с age-verification законами США (см. `05-business.md`). |
| 3 | **«Живость» = Live2D-риг, а не видео** | Один раз сгенерированная Live2D-модель даёт бесконечные реакции в рантайме при ~0 затрат GPU. Видео-подход (Wan Animate) — только для пре-рендеренных катсцен. |
| 4 | **Консистентность персонажа = LoRA + Ref-Adapter, апскейл не спасает** | Никакой «премиум-генерации» не будет, если героиня в каждой сцене новая. LoRA персонажа — единственный способ, который держит лицо на 50+ артах. |
| 5 | **Мозг героини = LLM + отдельная векторная память + граф персоны** | «Полная интерактивность» — это не чат-бокс, а память о тебе, расписание, инициатива. Это технически решаемо (см. `04-interactivity.md`), и это то, чего нет у Nikke. |

## Что делать на этой неделе (3 шага, без которых остальное бессмысленно)

1. **Проверить лицензии** на веса Anima (CircleStone) и Illustrious/NoobAI **до** коммерческого запуска — там есть non-commercial ограничения. Детали и альтернативы: `02-art-pipeline.md`, раздел «Лицензии — стоп-фактор».
2. **Сгенерировать 1 «эталонную» героиню** и обучить на ней LoRA (55–60 артов, ~2–4 часа на 4090). Без этого пайплайна нет — все остальные шаги на ней висят.
3. **Прогнать прототип через 5 живых людей** (не себя) и записать: сколько секунд до первого тапа по героине, сколько тапов за сессию, где отваливаются. Это вход в дизайн кор-лупа.
