Документ отвечает на претензию «стиль не нравится» не словами, а сменой
источника: раньше стиль собирался из моих формулировок, теперь — из корпуса
реальных промптов, атласа проверенных терминов и устройства манга-панели.

## 1. Что изменилось после отказа от v6

| | v6 (отклонён) | v7 |
|---|---|---|
| Стиль | один зашитый набор тегов | **параметр**: `--style ink-panel \| manhwa-color \| webtoon-drama` |
| Якоря | «глянцевая кожа, контровой свет» | у каждого регистра свои якоря **и свои запреты** |

| Качество/негатив | по опыту | из **корпуса 2481 промпта** с процентами |
| Композиция | интуитивно | из **грамматики панели** (Manga109) |

Три регистра — не вкусовщина, а разные производственные ветки:

- **`ink-panel`** — печатная страница: тушь, чёрные плашки, тон точками, палитра из трёх цветов.
- **`manhwa-color`** — цветной вебтун: толстый контур, плоский cel, приглушённый цвет. Регистр по умолчанию.
- **`webtoon-drama`** — baseline v6. Оставлен только чтобы было с чем сравнивать.

Доказательство: `assets/concept/_style_ballot.jpg` — одна героиня, три регистра.

## 2. Корпус промптов: цифры вместо интуиции

Источник: `jtatman/stable-diffusion-prompts-uncensored` (851 568 строк, **MIT**),
локально выкачано **2481** через rows API. Сбор — `tools/corpus_fetch.py`,
добыча — `tools/prompt_miner.py`.

Что реально стоит в промптах:

| Блок | Доля промптов |
|---|---|
| `masterpiece` | 56.6% |
| `best quality` | 55.7% |
| `1girl` | 42.6% |
| негатив `low quality` | **92.6%** |
| негатив `worst quality` | 89.0% |
| негатив `bad anatomy` | 68.8% |
| негатив `watermark` | 57.4% |
| негатив `bad hands` | 36.0% |

Практика по LoRA (средний вес в корпусе): `add_detail` — **0.77**,
`more_details` — **0.43**, `koreanDollLikeness` — **0.29–0.30**. То есть
детализацию ставят сильно, а LoRA на лицо — слабо, чтобы не «пережечь».

**Честные границы.** Корпус смещён в фотореализм: `chilloutmix`, `majicmix`,
`realistic`, `raw photo` — массовый NSFW делают на фотореалистичных моделях.
Слово `manhwa` в 2481 строке не встретилось ни разу. Поэтому разделение такое:
**техника** (качество, негативы, веса LoRA) — из корпуса, **аниме-лексика** — из
тегов Danbooru, где есть частоты. Два датасета с anime-тегами
(`Civiverse-SFW`, `Civitai-2m-prompts`) отдают HTTP 500 через datasets-server —
выкачать не удалось, это зафиксировано, а не замазано.

```bash
python3 tools/corpus_fetch.py --source jtatman --pages 20
python3 tools/prompt_miner.py --top 20
python3 tools/prompt_miner.py --cooccur anime
python3 tools/prompt_miner.py --fingerprint --wildcards
```

## 4. Грамматика манга-панели (объёмы Manga109)

Manga109 — самая большая открытая **размеченная** база манги: **109 томов**,
21 142 страницы, **103 900 панелей**, 157 152 персонажа, 118 715 лиц,
147 918 текстовых блоков, плюс диалоги (Manga109Dialog, 132 692 пары).
Лицензия исследовательская с обязательной атрибуцией — используем как
**справочник приёмов**, не как тренировочные данные.

Шесть приёмов, которые переносятся в промпт и композицию:

1. **Spot black** — крупная чёрная плашка вместо детального фона: фокус на фигуре.
2. **Screentone** — тон точками только в тени; кожу не заливать.
3. **Speed lines** — по краю кадра, не по лицу.
4. **Slant frame** — наклон панели подчёркивает давление сцены (наш NTR-регистр).
5. **Gutter bleed** — фигура выходит за панель: «не помещается в кадр».
6. **Eye line** — нижняя треть на уровне глаз сидящей фигуры; для стоящих — камера на бёдрах.

В промпте это `dramatic panel composition`, `spot blacks`, `screentone accents`,
в раскладке — 70–80% высоты кадра и запас по краям.

## 5. Как это использовать в Arena.ai agent mode

Проблема, из-за которой это вообще понадобилось: ответ забракован фразой
«не нравится», а агенту в новой сессии не видно ни переписки, ни причин.

Протокол турнира (по мотивам Arena-skill и практики Agent Arena):

1. **`task.md`** — самодостаточная задача: что сделать, **что именно отвергнуто и
   почему**, твёрдые ограничения из канона, точные пути файлов, что сдать.
2. **`cards.md`** — по одной стратегии на агента, без повторов: first principles,
   inversion, adversarial, constraint first, worked example, simplest, edge cases,
   systems thinking.
3. **`rubric.md`** — 5 критериев с якорями 0–10: регистр, фигура, артефакты,
   уровень горячести, узнаваемость. `fatal` только за проверенный брак.
4. **Слепой судья** сравнивает X и Y; `fatal` не может выиграть.

```bash
python3 tools/arena_task.py --heroine selena --kind tournament --heat 2 --model illustrious
# → tasks/arena/selena-style-tournament-L2/{task.md,rubric.md,cards.md,baseline.md,README.md}
```

Правило размеров: 16 агентов — рутина, 100 — решение, которое определяет продукт.
Смена стиля — второе.

## 6. Что дальше

- Выбрать регистр (A / B / C на бюллетене) → он становится дефолтом в каноне.
- Пересобрать весь каст в выбранном регистре и прогнать через `make qa-render`.
- Дособрать атлас: термины группы `fetish_feet` проверить позами из `assets/pose/`.
- Если HF отпустит — добрать anime-корпус, чтобы фингерпринт перестал быть фотореалистичным.
