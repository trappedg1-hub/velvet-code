# 06 · Дорожная карта: 12 недель до закрытой беты

Команда-минимум: **2 человека** (геймдизайн+арт-пайплайн, разработка). Ниже — то, что реально успеть вдвоём, если не распыляться.

---

## Фаза 0 · Неделя 1–2: фундамент (не пропускать)

| Задача | Результат |
|---|---|
| Проверить лицензии весов (Anima / Illustrious / Qwen / TTS) | письменное решение, на чём производство |
| Написать в CircleStone Labs про коммерческую лицензию | ответ или план Б |
| Юрлицо + платёжный путь (или заявка паблишеру) | известно, **куда** придут деньги |
| Настроить ComfyUI + Anima Turbo/Aesthetic + Qwen-Image-Edit | рабочий локальный/облачный пайплайн |
| **Арт-библия**: 1 эталонная героиня, 20–30 концептов, выбранный стиль | папка `artbible/` с эталоном |
| Обучить LoRA на 55–60 артах | `.safetensors`, который держит лицо |
| Age-gate + ToS + политика 18+ | черновики готовы |

**Выход фазы:** можете сгенерировать 20 артов одной героини, и она везде одна и та же. Без этого дальше идти нельзя.

## Фаза 1 · Неделя 3–4: «живая» героиня

| Задача | Результат |
|---|---|
| See-through: эталонный арт → PSD (23 слоя) | `selena_psd/` |
| Пост-обработка (`seethrough-live2d-pipeline`) | PSD читается Cubism |
| Авториг (`image-to-live2d` / `AIlive2dpsd`) | `.moc3` + `.cmo3` |
| 2–3 часа ручной доводки в Cubism Editor | риг не «ломается» в крайних позах |
| Рантайм: pixi.js v8 + `@jannchie/pixi-live2d-display` | героиня в браузере, 60 fps |
| Поведенческий слой: idle-цикл, anticipation, gaze, blink | она двигается без команд |
| Hit-зоны из модели (`model.on('hit')`) | реакции на тап по частям тела |

**Выход:** заходите на страницу — она стоит, дышит, смотрит за курсором, мигает, реагирует на тап. **Это тот момент, когда становится понятно, что идея работает.**

**Выход:** можно поговорить с героиней голосом и текстом, и она отвечает в характере, помня прошлый разговор.

## Определение «100% результата» — чеклист приёмки беты

- [ ] Три героини, каждая — узнаваемая в любом ракурсе (проверка: 10 артов, слепой тест «это одна и та же?»)
- [ ] Каждая — Live2D-риг, мигает, дышит, смотрит, липсинкает
- [ ] Каждая — говорит голосом, минимум 150 реплик на 4 настроения
- [ ] Память работает: во 2-й сессии она ссылается на 1-ю
- [ ] Инициатива: если 30 сек ничего не делать — она сама заговорит
- [ ] 8+ тач-зон с разными реакциями и «терпением»
- [ ] Гардероб: минимум 3 скина на героиню, покупка работает
- [ ] Оплата проходит end-to-end (тестовая карта → разблокировка)
- [ ] Age-gate до контента
- [ ] 60 fps desktop / 30 mobile, первый кадр < 1.5 с
- [ ] Аналитика пишет все события
- [ ] 100 живых тестеров прошли онбординг, D1 ≥ 25%

## Что делать буквально завтра

1. Открыть `prototype/index.html`, пройти его 5 раз подряд и записать, что раздражает. Это ваш первый геймдизайн-док.
2. Запустить ComfyUI, поставить Anima Turbo, сгенерировать 30 вариантов лица одной героини, выбрать эталон.
3. Написать письмо в CircleStone Labs про коммерческую лицензию (5 минут, а снимает главный риск).
