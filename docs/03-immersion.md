# 03 · «Живая героиня» — стек иммерсивности

Задача: чтобы героиня **дышала, смотрела, реагировала и говорила**, а не была картинкой с кнопками. Ниже — 5 уровней, от дешёвого к дорогому, с честной ценой каждого.

| Уровень | Технология | Эффект «живости» | Стоимость | Когда |
|---|---|---|---|---|
| **L0** | Спрайт + CSS/JS-трансформации | 25% | 0 | Прототип (уже сделано) |
| **L1** | **Live2D-риг** (.moc3) | **75%** | 1–2 дня на героиню | MVP |
| **L2** | Live2D + процедурный «мозг тела» | 85% | +2 дня кода | MVP |
| **L3** | Пре-рендер видео (Wan Animate 2.2) | 90%, но неинтерактивно | $5–40 за клип | Особые сцены |
| **L4** | Реалтайм-нейроаватар (LivePortrait/MuseTalk) | 95% | GPU на каждого игрока | Не для браузера |

**Рекомендация: L1 + L2 в основном продукте, L3 — для 3–5 «вау»-сцен.** L4 в браузере в 2026 не окупается: серверный GPU на игрока убивает юнит-экономику.

---

## 1. L0 — что уже есть в прототипе (и почему этого мало)

`prototype/index.html` реализует: дыхание (CSS-анимация scale), параллакс-взгляд за курсором (rig-трансформация + сдвиг rim-light), «дёрганье» на тач, 8 hit-зон, настроение, влияющее на фильтр/свет/реплики.

Этого достаточно, чтобы **проверить кор-луп**, но недостаточно для продакшна: нет мигания, нет липсинка, нет физики волос, «дёрганье» двигает всё тело сразу (в риге двигается только торс, а голова остаётся).

---

## 2. L1 — пайплайн «арт → риг» (то, что раньше занимало неделю)

Классический путь: художник вручную режет PSD на 30+ слоёв и ригает в Cubism Editor (6–12 часов на персонажа). С 2026 это автоматизируется:

```
один арт (фронтальный, чистый силуэт)
   │
   ├─► See-through (ComfyUI) ──────────► PSD, 23–24 слоя + depth-карты      [~25 мин, 24GB VRAM]
   │
   ├─► seethrough-live2d-pipeline ─────► PSD, пригодный для Cubism          [пост-обработка]
   │     (Kota-Ohno: reproject 4096px, refine_edges, clean_face, ag-psd)
   │
   └─► авториг
         ├─ lvhaojie456/image-to-live2d   → .moc3 + .cmo3 + отчёт валидации
         ├─ giantiensinh/imagelive2d      → .moc3 / .inp / .cmo3 (IRR-формат)
         ├─ zhangxiaoyu66666/AIlive2dpsd  → psd2live: меши, деформеры, физика
         └─ OleksandrSelehei/RigForge-2D  → открытый движок авто-рига
                    │
                    ▼
              .moc3 + model3.json + physics3.json + idle.motion3.json
```

Важно понимать: результат авторига — **первый проход, а не готовый ассет**. Он уже двигается (мигает, качает головой, физика волос), но требует 1–3 часов ручной доводки в Cubism Editor. Это всё равно в 4–6 раз быстрее ручной сборки.

Валидация качества рига (та же, что в `image-to-live2d`): 363 тестовых позы, проверка на вывернутые треугольники и **дрейф стопы < 0.25 px** — критично для вашей темы, где стопы в кадре.

⚠️ Юридическое: **nizima запрещает продажу Live2D-моделей, сделанных из AI-иллюстраций** (политика на 07.2026). Для собственной игры внутри своей платформы это не блокер, но перепродавать модель как ассет нельзя.

## 3. L1-рантайм: что рендерит героиню в браузере

| Вариант | Вердикт |
|---|---|
| **pixi.js v8 + `@jannchie/pixi-live2d-display`** | ✅ **Выбор.** WebGPU-first, поддержка Cubism 2.1/3/4, липсинк из аудио/микрофона/вручную, мигание, дыхание, физика (Cubism 4), автоматический hit-testing зон, RenderTexture и фильтры (можно накладывать bloom/тепловую дымку на персонажа) |
| `RaSan147/pixi-live2d-display-lipsyncpatch` | ✅ Альтернатива с акцентом на липсинк (PixiJS 7) |
| Официальный Cubism Web Framework | ❌ Сложный API, много кода-обвязки |
| Phaser 4 | ⚠️ Живой рендерер, но Live2D придётся интегрировать через Pixi-плагин внутри сцены |
| Godot 4.7 web export (WebGL2) | ⚠️ C# на web не экспортируется, билд ~5 MB; оверкилл для VN |
| Three.js/VRM 3D | ❌ Дороже по контенту, теряется манхва-стилистика |

Базовая интеграция:

```js
import { Application, Ticker } from 'pixi.js';
import { Live2DModel } from '@jannchie/pixi-live2d-display';

const app = new Application();
await app.init({ canvas, resizeTo: window });
const model = await Live2DModel.from('/models/selena/selena.model3.json', { ticker: Ticker.shared });
app.stage.addChild(model);

// hit-tests = ваши тач-зоны, приходят из модели
model.on('hit', areas => {
  if (areas.includes('Thigh')) heroine.react('thigh');
});

// липсинк прямо из воспроизводимого аудио
model.speak(audioUrl);
```

**Настройки качества жизни** (без них модель выглядит мёртвой):

| Параметр | Как вести себя |
|---|---|
| `ParamAngleX/Y/Z` | взгляд за курсором с **лагом 120–200 мс** (мгновенно = робот) |
| `ParamEyeLOpen/ROpen` | мигание через случайный интервал 2.5–6 с + «двойные» мигания иногда |
| `ParamMouthOpenY` | амплитуда аудио (RMS) с ограничением скорости |
| `ParamBodyAngleX/Y/Z` | перенос веса раз в 8–15 с, не синхронно с дыханием |
| `ParamBreath` | базовая частота 0.22 Гц, при `hot`-настроении +20% |
| физика (physics3.json) | волосы и ткань **обязательно**, это 30% ощущения живости |

## 4. L2 — «мозг тела»: процедурный слой поверх рига

То, что отличает «модель из магазина» от «живой героини» — не риг, а **поведение между действиями**. Реализуется как отдельный стейт-машина (в проде — `behaviour.ts`, ~600 строк):

1. **Idle-цикл**: поза «стоит» → «переносит вес» → «поправляет волосы» → «смотрит в сторону» → снова. Интервалы случайные (8–20 с), без повторов подряд.
2. **Anticipation**: до ответа 150–300 мс микродвижение (вдох, поднятие брови) — это резко повышает ощущение, что она «думает».
3. **Gaze**: если курсор без движения 4 с — она смотрит на тебя; если ты тапаешь часто — отводит взгляд (смущение/раздражение).
4. **Настроение → тело**: `cold` — руки скрещены, минимум движения, взгляд в сторону; `hot` — наклон вперёд, чаще смотрит в камеру, дыхание глубже.
5. **Реакция на тач**: hit-area → выбор анимации из пула по (зона × настроение); повтор одного и того же места 3 раза за 5 с → «терпение» падает, реакция становится холодной (это уже есть в прототипе).
6. **Расписание**: у героини есть «жизнь» — в 14:00 она «на репетиции» (другая локация/костюм), в 23:00 «дома» (другая подача). Смена по реальному времени даёт ощущение, что мир живёт без тебя.

## 5. Голос: TTS

| Модель | Качество | Эмоции | Лицензия | Вердикт |
|---|---|---|---|---|
| **GPT-SoVITS** | 8/10 клонирование с 5 сек, файнтюн с 1 мин | слабо | **MIT** ✅ | **Основной выбор** для прода |
| **IndexTTS-2.5** (bilibili) | 8.5/10, точный контроль эмоции/длительности | **сильно** | Bilibili License ⚠️ | Лучший звук, нужен грант на коммерцию |
| Chatterbox / CosyVoice 2 | 8/10, мультиязычно | средне | проверить | Резерв |
| F5-TTS | 8/10 клонирование | нет | CC-BY-**NC** ❌ | Только для прототипов |

**Архитектурное решение, которое экономит 90% денег:** 80% реплик в игре — заранее известны. Их **не надо синтезировать в рантайме**: генерируем один раз, кладём `.ogg` (Opus, 32 kbps mono) в CDN. Рантайм-TTS нужен только для свободного ввода (LLM-ответы), и там допустима задержка 500–900 мс, если параллельно играет анимация «она думает».

Формат озвучки одной героини: 6 уровней настроения × ~40 реплик × 5 зон = ~1200 файлов ≈ 15–25 MB Opus. Это копейки для CDN.

## 6. Липсинк

| Метод | Где | Стоимость |
|---|---|---|
| **Амплитудный (RMS → ParamMouthOpenY)** | рантайм, встроен в pixi-live2d | $0, «достаточно хорошо» для 2D-манхвы |
| Фонемный (если TTS отдаёт тайминги) | рантайм | точнее, чуть больше кода |
| **MuseTalk / LatentSync / EchoMimic** | офлайн, для пре-рендеренных катсцен | GPU-секунды |
| LivePortrait / LiveTalking | реалтайм-аватар | не для браузера |

Для 2D-рига амплитудного липсинка **достаточно** — зритель не ждёт фотореализма от манхвы. Не тратьте здесь время.

## 7. L3 — видео-сцены: Wan 2.2 Animate

**Wan2.2-Animate-14B** (Alibaba Tongyi, Apache 2.0, релиз 19.09.2025) — открытая модель, которая делает ровно то, чего не может Live2D:

- **Animation mode**: одна картинка персонажа + драйв-видео → персонаж повторяет движение тела, мимику и артикуляцию;
- **Replacement mode**: заменить человека в существующем видео, сохранив свет и камеру;
- препроцессинг: YOLOv10 (детекция) + ViTPose-L WholeBody (скелет по кадру);
- железо: **24 GB VRAM** для комфортного 720p (или fp8/GGUF-кванты + ComfyUI `WanVideoWrapper`, `KJNodes`, `VideoHelperSuite`, `WanAnimatePreprocess`).

Где применять: **3–5 ключевых сцен** (первое свидание, «особый» вечер, разблокировка уровня 6). 6–10-секундный клип в 720p, зацикленный с crossfade, даёт эффект «она правда двигается», которого Live2D не даст.

Экономика: ~$0.10–0.50 за секунду видео в облаке → клип 8 сек ≈ $1–4. Пять клипов на героиню ≈ $5–20. Дешевле, чем один день аниматора.

Драйв-видео: снимайте себя/друга на телефон по референсу позы — модель переносит движение. Это законно и бесплатно.

## 8. Бюджет производительности в браузере

| Метрика | Цель |
|---|---|
| Первый кадр героини (LCP) | < 1.5 с на 4G |
| Размер модели на героиню | ≤ 3–5 MB (атлас 2048² + moc3 + motions) |
| FPS | 60 desktop / 30 mobile (риг нетребователен, WebGPU) |
| Память | ≤ 250 MB на вкладку |
| Загрузка | ленивая: ассеты следующей героини — по idle-таймеру |

Атласы текстур собирать в WebP, а не PNG (экономия 60–70%). `model3.json` + `physics3.json` — кэшировать на CDN с immutable-заголовками.
