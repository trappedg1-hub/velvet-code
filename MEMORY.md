## 2. Задача владельца (в его терминах)

NSFW adult game **«VELVET CODE»**: 7 героинь, спрайты, канон, пайплайн промптов и QA,
движок на PixiJS. Стиль — **уровень реальной манхвы/хентай-аниме**, не «AI-рендер».

Действующие критерии приёмки:

1. Работать **только в режиме mature** (прямое указание); green — витрина и гейт 18+.
2. Героинь **генерировать и предъявлять на утверждение**, учитывать весь накопленный контекст.
3. **Ткани в промптах**: материалы, которые облегают, просвечивают, рвутся — и всё это
   должно быть в инструменте, а не только в тексте.
4. **Персонажи без фона**: хромакей → чистый альфа-спрайт.
5. **Без артефактов** — в пайплайне есть инструмент-ремонтник.
6. **Ресёрч внешний и предметный** (интернет, GitHub, конкретные примеры), инструменты
   **подключать, а не перечислять**. Арена откровенности (потолок 164), механика SeaArt
   Green/Mature, регистр `hentai-render`, стопы petite 0.75–0.85 головы.

## 7. Ошибки и тупики (не повторять)

1. **GitHub-коннектора нет.** Пушить можно только по токену через `tools/push_github.sh`
   или руками владельца. Не выдавать это за автоматический деплой. Vercel подключён, но
   ему тоже нужен git-remote.
2. **Fine-grained токен не создаёт репозитории** (`POST /user/repos` → 403
   «Resource not accessible»). Репозиторий создаёт человек, дальше пуш работает.
3. `pipeline_sprites --reindex` **уничтожал якоря** → лечится сохранением `anchors`
   в `_rebuild_index`. Была регрессия в тестах — теперь закрыта.
4. **Автофиксы не спасают брак кадра.** Nova была светлее канона (tan skin), у Айрин
   не читалась снятая туфля → только пересъёмка. Не тратить время на ретушь.
5. `qa_sprites` **не видит анатомию** — «ласту» считает нормой. Глазами смотреть лист.
6. Заливка всех дырок по контуру → **чёрная плита**. `cv2.COLOR_BGR2BGR` не существует.
7. `generate_image` — **лимит 10 картинок за ход**; планировать партиями.
8. `fabric.check()` требует **явный список поведений** ткани, иначе молчит.
9. Тест heat-3 **падает в green** — это ожидаемо, режим green неполный по замыслу.
10. **Реквизит в кадре** (пуф, блок, мебель) попадает в спрайт → генерировать без мебели.
11. Регистр B «комикс» и equal-height composite — **отклонены владельцем**, не предлагать.

## 10. Как общаться с владельцем

Формат ответа — всегда:

```
СДЕЛАНО: …
ПРОВЕРЕНО: make test (N passed) · make canon-check (ok|drift)
ФАЙЛЫ: …
ЖДЁТ ЧЕЛОВЕКА: … или "нет"
```

Владелец не любит перечислений «можно сделать так, так и так» — он говорит «берём всё и делаем».
Не спрашивать разрешения на каждый шаг, спрашивать только на необратимое (новый каст, смена
регистра). Не оправдываться, показывать результат и числа.

## 11. Репозиторий

Ветка `main`. Аккаунт владельца: **trappedg1-hub**. Репозиторий создаёт человек
(fine-grained токен этого не может) → потом:

```bash
GH_TOKEN=<fine-grained-token> tools/push_github.sh <user>/<repo> --check
GH_TOKEN=<fine-grained-token> tools/push_github.sh <user>/<repo>
```

Токен живёт только в команде: скрипт после пуша перезаписывает remote на чистый URL.
`.env` и токены в git не кладём никогда — в `.env.example` только имена переменных.
